# Court Booking Service – User Stories

## 1. Customer User Stories

### US-01: User Registration
As a customer, I want to create an account so that I can book sports courts.

**Acceptance Criteria:**
- Users can register with their details.
- The system validates the entered information.
- Users can log in after registration.

### US-02: Search Courts
As a customer, I want to search courts by location and sport so that I can find suitable courts.

**Acceptance Criteria:**
- Users can select a sport.
- Users can search by location.
- Matching courts are displayed.

### US-03: Check Availability
As a customer, I want to check available time slots so that I can choose a suitable time.

**Acceptance Criteria:**
- Users can select a date.
- Available and booked slots are displayed.
- Booked slots cannot be selected.

### US-04: Book a Court
As a customer, I want to book an available court so that I can play my preferred sport.

**Acceptance Criteria:**
- Users can select a court and time slot.
- The system checks availability before confirmation.
- A booking ID is generated.
- Booking details are saved.

### US-05: Cancel Booking
As a customer, I want to cancel my booking so that I can change my plans.

**Acceptance Criteria:**
- Users can view their bookings.
- Eligible bookings can be cancelled.
- Booking status is updated.

## 2. Court Owner User Stories

### US-06: Manage Courts
As a court owner, I want to add and update court details so that customers can see accurate information.

**Acceptance Criteria:**
- Owners can add courts.
- Owners can update court details.
- Owners can deactivate courts.

### US-07: Manage Availability
As a court owner, I want to manage available time slots so that customers can book courts at suitable times.

**Acceptance Criteria:**
- Owners can set operating hours.
- Owners can block unavailable slots.
- Updated availability is reflected in the system.

## 3. Admin User Stories

### US-08: Manage Users
As an admin, I want to manage user accounts so that I can maintain the platform.

**Acceptance Criteria:**
- Admin can view users.
- Admin can manage user status.

### US-09: Manage Bookings
As an admin, I want to view bookings so that I can monitor reservations.

**Acceptance Criteria:**
- Admin can view booking details.
- Admin can filter bookings.
- Admin can manage booking status.

### US-10: Manage Pricing
As an admin, I want to manage court pricing so that booking prices remain accurate.

**Acceptance Criteria:**
- Admin can set prices.
- Admin can update prices.
- Updated prices are reflected in bookings.
